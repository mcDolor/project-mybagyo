# Project MyBagyo ⛅

### 🎯 Project Overview
---
A dynamic, responsive weather dashboard built in partial fulfillment for our laboratory activity in Platform-Based Development course.

&ensp;

### 🛠️ Tech Stack
---
* **Frontend Framework:** React + Next.js
* **Styling:** css Flexbox & Grid
* **API:** OpenWeatherMap API
* **Data Fetching:** Axios

&ensp;

### 🚀 Core Features & Grading Requirements
---
* **Search Functionality:** Users can input a city to retrieve live weather data.
* **Weather Display:** Shows Current Temperature, Weather Condition, and the appropriate Weather Icon.
* **Responsive Layout:** 
  * Mobile: Vertical stacking
  * Tablet: Adjusted spacing
  * Desktop: Expanded multi-column layout
* **Error Handling & State:** Includes loading spinners, invalid city input alerts, and network failure fallbacks.
* **Performance Optimization:** To be updated...

&ensp;

### 💻 Local Setup Instructions
---
1. Clone the repository: 
`git clone https://github.com/mcDolor/project-mybagyo.git`
2. Navigate into the directory:
`cd project-mybagyo`
3. Install dependencies:
`npm install`
4. Set up environment variables:
* Create a `.env.*` file in the root directory.
* Add your OpenWeatherMap API key:
5. Start the development server:
`npm run dev`
